## 📖 Overview

**Planzo.ai** is an intelligent, AI-powered travel assistant designed to revolutionize how you plan your trips. By analyzing your budget, travel dates, mood, and interests, Planzo generates comprehensive, day-wise itineraries in seconds.

Gone are the days of browsing dozens of websites. Planzo acts as your personal digital travel agent, offering structured plans, budget health checks, and personalized recommendations—all in a modern, user-friendly interface.

---

## ✨ Key Features

- **🤖 AI-Driven Itinerary Generation**: Get detailed day-wise plans streamed in real-time.
- **💰 Smart Budget Management**:
  - Live budget slider with visual tiers (Budget, Moderate, Premium, Luxury).
  - Real-time budget health monitoring and expense breakdown.
- **🎭 Mood-Based Personalization**: Tailor trips for *Adventure*, *Relaxation*, *Romance*, *Family*, or *Solo* travel.
- **📍 Rich Destination Insights**:
  - Interactive maps and location highlights.
  - "Must-try" food spots and activity recommendations.
- **🎒 Travel Utilities**:
  - Automated packing checklists.
  - Safety tips and local transport guides (Budget vs. Comfort).
- **🔐 Secure User Accounts**: Sign up to save your favorite trips and access them anytime (powered by Supabase).

## 🚀 Getting Started

Follow these steps to set up the project locally.

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/planzo.ai.git
   cd planzo.ai
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment Variables**
   Create a `.env` file in the root directory and add your Supabase credentials:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_anon_key
   ```

4. **Run the development server**
   ```bash
   npm run dev
   ```
